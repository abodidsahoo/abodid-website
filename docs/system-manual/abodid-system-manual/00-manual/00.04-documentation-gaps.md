# 00.04 — Documentation Gaps Audit

Status: Current  
Last Audited: 2026-09-18  

---

## 1. Purpose of This Audit

In accordance with Section 10 of the System Manual charter, this document explicitly registers any subsystem, legacy table, route, or external dependency whose production state or configuration could not be verified with 100% certainty.

Rather than making ungrounded assumptions or guessing missing information, gaps are cataloged here for developer follow-up.

---

## 2. Identified Gaps and Verification Items

### 2.1. Legacy Webflow Redirection
- **Subsystem / Area**: Legacy Routing & Cleanup
- **Nature of Gap**: Legacy cleanup script references Webflow tables that were dropped in database migration `20260127_cleanup_webflow_tables.sql`.
- **Code Reference**: `src/pages/api/cleanup-webflow.js`
- **Recommended Verification**: Confirm if `cleanup-webflow.js` API route can be safely deleted or if external clients still ping it.

---

### 2.2. Supercut Club Matching Backend
- **Subsystem / Area**: Commercial & Matchmaking Services
- **Nature of Gap**: Frontend page routes exist (`src/pages/supercutclub/*`), but matching engine Supabase tables are partially deprecated in favor of unified services.
- **Code Reference**: `src/pages/supercutclub/`
- **Recommended Verification**: Audit live Supabase database to confirm active tables for Supercut Club editor matching.

---

### 2.3. Anonymous Auth Configuration
- **Subsystem / Area**: Authentication & User Sessions
- **Nature of Gap**: Local setup documentation mentions anonymous auth (`ENABLE_ANONYMOUS_AUTH.md`), but production Supabase project settings require manual toggle in dashboard.
- **Code Reference**: `src/lib/anonymousAuth.ts`
- **Recommended Verification**: Verify that anonymous sign-in is toggled to ON in production Supabase Auth settings.

---

### 2.4. Daily Reading Digest Cron Execution
- **Subsystem / Area**: Background Jobs & Automation
- **Nature of Gap**: Database schema defines `pg_cron` schedule at `08:00 Asia/Kolkata`, but local development environments do not run `pg_cron` without manual Supabase CLI extensions.
- **Code Reference**: `supabase/migrations/20260804100000_create_daily_reading_digest.sql`
- **Recommended Verification**: Verify `cron.job` status in live Supabase SQL editor.

---

### 2.5. Private Client Galleries
- **Subsystem / Area**: Media Delivery & Asset Protection
- **Nature of Gap**: Architecture supports signed R2 URL generation for private photography deliverables, but dynamic password-gated client portal UI is in WIP state.
- **Code Reference**: `src/lib/media/r2.ts`
- **Recommended Verification**: Document client gallery password hashing table when finalized in next migration.

---

## 3. Gap Resolution Protocol

When a gap is audited and resolved:
1. Update the corresponding specification file (e.g., in Chapter `06` or `08`).
2. Update the status tag from `Status: Unverified` to `Status: Current`.
3. Record the resolution in [CHANGELOG.md](../CHANGELOG.md) and remove the item from this list.
