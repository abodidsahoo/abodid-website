## 1. Slug Generation Logic

Slugs across all content systems (Work, Research, Blog, Obsidian Vault) follow strict deterministic normalization rules:

```javascript
function generateCanonicalSlug(title) {
  return title
    .toLowerCase()
    .trim()
    .replace(/[^\w\s-]/g, '')    // Remove non-alphanumeric except whitespace and hyphens
    .replace(/[\s_-]+/g, '-')    // Collapse whitespace and underscores to single hyphen
    .replace(/^-+|-+$/g, '');    // Strip leading and trailing hyphens
}
```

### 1.1. Invariant Rules
- **Immutability After Publication**: Once a slug is published and indexed in `sitemap.xml`, it cannot be changed without creating an explicit redirect entry in `vercel.json`.
- **Case Sensitivity**: All routes and slugs are strictly lower-case.
- **Trailing Slash Removal**: Astro and Vercel enforce `trailingSlash: false`. Any request with a trailing slash receives a `308 Permanent Redirect` to the stripped path.

## 3. Canonical URL Enforcement

Every HTML page rendered by Astro injects a `<link rel="canonical" href="...">` pointing to `https://abodid.com${canonicalPath}`.

- Strips tracking query parameters (`utm_*`, `ref`, `fbclid`).
- Preserves functional state queries where relevant (e.g., `/work?category=spatial`).
- Enforces HTTPS protocol.
