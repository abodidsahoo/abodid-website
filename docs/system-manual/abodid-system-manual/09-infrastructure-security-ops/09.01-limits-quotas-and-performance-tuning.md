# 09.01 — Service Quotas, CPU Limits, and Cost Optimization

Status: Current  
Last Updated: 2026-09-18

## 1. Service Quota Boundaries

To maintain predictable operational costs and prevent unexpected downtime on free/pro tier boundaries, the architecture enforces the following operational limits:

| Infrastructure Layer | Metric / Resource | Hard Quota / Boundary | Architectural Mitigation |
| :--- | :--- | :--- | :--- |
| **Vercel** | Fluid Active CPU | 100 hrs/month | Aggressive static pre-rendering (`output: 'static'`) keeps CPU time near zero for public traffic. |
| **Vercel** | Serverless Invocations | 1,000,000 / month | Public pages served from CDN edge cache; API endpoints rate-limited. |
| **Supabase** | Connection Pooling | 60 Max Connections | Node serverless functions use Supabase REST endpoints (PostgREST) rather than direct persistent TCP pool connections. |
| **Supabase** | Database Disk Storage | 500 MB (Free) / 8 GB (Pro) | Media stored in Cloudflare R2; Postgres holds only structured text, metadata, and vectors. |
| **Cloudflare R2** | Egress Bandwidth | Zero Egress Fees | Free egress from R2 allows unlimited media delivery through Cloudflare edge cache. |
| **OpenRouter** | Token Spend Rate | Configured limit | Batch embeddings and small models (`gemini-2.5-flash`) keep monthly AI costs under nominal budget. |

## 2. Performance Tuning Invariants

1. **Asset Hashing**: All CSS, JS chunks, and generated fonts include deterministic content hashes (`[name].[hash].js`) enabling 1-year immutable edge caching.
2. **Font Preloading**: Satoshi variable font files are preloaded via `<link rel="preload" as="font" type="font/woff2" crossorigin>` to prevent layout shifts (CLS < 0.01).
3. **Payload Truncation**: Admin analytics and network intelligence endpoints enforce strict pagination (`limit: 50` or `pageSize: 1000`) to prevent Node memory spikes.
