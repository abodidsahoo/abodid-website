Status: Current

## 1. Pipeline Overview

The **Obsidian Knowledge System** connects a private local Obsidian markdown vault to the public web interface (`/obsidian-vault`) and an AI-powered semantic search engine.

```mermaid
graph LR
    LocalVault[Local Obsidian Desktop Vault] -->|Git Push| GitHubRepo[GitHub: abodidsahoo/obsidian-vault]
    GitHubRepo --> IngestScript[scripts/ingest-obsidian-vault.mjs]
    IngestScript --> ChunkEngine[Text Chunking & Privacy Filter]
    ChunkEngine --> Embeddings[OpenRouter text-embedding-3-small]
    Embeddings --> SupabasePG[(Supabase pgvector: obsidian_chunks)]
    SupabasePG --> VaultChatAPI[/api/vault-chat & /api/vault-tag-search]
```

---

## 2. Ingestion Execution Flow (`scripts/ingest-obsidian-vault.mjs`)

1. **Vault Fetch**: Downloads the current branch tarball from GitHub (`api.github.com/repos/abodidsahoo/obsidian-vault/tarball/main`).
2. **Selective Path Ingestion**:
   - Includes: `06-main-notes/`, `6 - Main Notes/`.
   - Excludes: `.git/`, `.obsidian/`, `Attachments/`, `.trash/`.
3. **Sensitive Content Detection**:
   - `detectSensitiveVaultContent()` inspects notes for private contact details, API keys, or unpublished personal journals, automatically flipping `is_public = false`.
4. **Chunking & Hashing**:
   - Splits long notes into semantic chunks (~500 tokens with 50-token overlap).
   - Generates SHA-256 content hashes to skip re-embedding unchanged notes.
5. **Vector Embedding**:
   - Dispatches batches of 16 chunks to OpenRouter embeddings API (`text-embedding-3-small`, 1536 dimensions).
   - Upserts embeddings into Supabase `obsidian_chunks` with pgvector cosine distance indexing (`vector_cosine_ops`).

---

## 3. Public Web Presentation

- Public notes render at `/obsidian-vault/[...slug]`.
- Wikilinks `[[Note Title]]` are parsed into dynamic internal links.
- Contextual backlink drawers dynamically surface related notes using vector similarity RPC (`match_obsidian_chunks`).
