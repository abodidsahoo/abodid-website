## 2. Code Standards and Invariants

1. **TypeScript Strictness**: All new modules in `src/lib/` and `src/components/` must be authored in typed TypeScript (`.ts`, `.tsx`).
2. **Path Aliasing**: Prefer relative path imports or standard root imports (`../lib/...`).
3. **No Direct Secret Injection**: Never read `process.env` secrets directly into client-hydrated Astro frontmatter. Server-only secrets belong inside `src/lib/supabaseServer.ts` or serverless API routes.
4. **Linting & Formatting**: Follow established ESLint and Prettier conventions without adding intrusive ad-hoc overrides.
