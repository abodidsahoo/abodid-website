## 1. Active Field Notes and Explorations

### 1.1. WebGPU Compute Shaders for Real-Time Film Emulation
- **Inquiry**: Can standard WebGL shader passes in the browser be replaced with WebGPU compute pipelines to simulate photochemical grain scattering and halation at 120fps?
- **Current Observation**: WebGPU support across mobile browsers remains fragmented; fallback to WebGL / SVG filter matrix remains mandatory for production.

### 1.2. Local Neural Audio Synthesis for Ambient Case Studies
- **Inquiry**: Embedding tiny ONNX models (~15MB) directly into the browser to generate non-repeating procedural ambient soundscapes tailored to user scroll velocity.
- **Status**: Prototype testing in scratch environment; evaluating audio thread CPU impact.

### 1.3. Spatial Computing and WebXR Exhibition Walkthroughs
- **Inquiry**: Streaming photogrammetry scans of physical gallery builds (*Into the Flux*) directly to Apple Vision Pro / Quest headsets via WebXR standard primitives.
