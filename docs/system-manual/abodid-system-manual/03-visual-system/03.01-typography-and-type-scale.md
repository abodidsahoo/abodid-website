# 03.01 — Typography Hierarchy and Type Scale

Status: Current  
Last Updated: 2026-09-18  

---

## 1. Font Family Stacks

The design system standardizes on three precise typographic tiers:

```css
:root {
  /* Primary Display, Headings, and Body Copy */
  --font-display: "Satoshi-Variable", "Satoshi-Regular", "Poppins", sans-serif;
  --font-body: "Satoshi-Variable", "Satoshi-Regular", "Poppins", sans-serif;

  /* Monospace Metadata, Eyebrows, Code, and System Readouts */
  --font-mono: "Satoshi-Variable", "Satoshi-Regular", "Space Mono", "Inconsolata", monospace;

  /* Editorial Accent / Literary Serif Fallback */
  --font-serif: "Cardo", "Georgia", serif;
}
```

## 2. Fluid Typographic Scale

Typography scales fluidly using CSS `clamp()` to ensure immediate readability without jarring breakpoint shifts:

| Typographic Role | Weight | CSS Declaration | Tracking | Leading |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Identity** | 720 | `clamp(2.8rem, 4.5vw, 5rem)` | `-0.075em` | `0.82` |
| **Hero Descriptor** | 480 | `clamp(1.2rem, 1.75vw, 1.85rem)` | `-0.025em` | `1.15` |
| **Hero Statement** | 300 | `clamp(2.25rem, 3.6vw, 4.2rem)` | `-0.03em` | `0.96` |
| **Major Section Heading** | 620 | `clamp(3rem, 6.7vw, 7rem)` | `-0.065em` | `0.90` |
| **Project / Card Heading** | 620 | `clamp(1.65rem, 2.6vw, 3.2rem)` | `-0.045em` | `0.96` |
| **Body Paragraphs** | 450 | `clamp(0.94rem, 1.12vw, 1.1rem)` | `normal` | `1.45–1.6` |
| **Eyebrow / Metadata Mono** | 750 | `clamp(0.68rem, 0.9vw, 0.78rem)` | `+0.08em to +0.11em` | `1.35` |

## 3. Typographic Invariants

- **Heading Tracking**: Large headings (`>2rem`) use tight negative letter-spacing (`-0.03em` to `-0.075em`) and sub-1.0 line heights to maintain poster-like density.
- **Eyebrow Casing**: All metadata eyebrows and category tags are strictly `text-transform: uppercase` with wide letter-spacing (`+0.08em`).
- **Text Wrapping**: All display headings declare `text-wrap: balance`; all body intros and summaries declare `text-wrap: pretty`.
- **Link Underlining**: Underlines attach exclusively to the text label span (`text-underline-offset: 3px`). Trailing navigation arrows (`↗`, `→`) must remain un-underlined.
