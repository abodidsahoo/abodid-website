## 1. Core Component Primitives

### 1.1. Project and Feature Cards
- **Geometry**: Tall, image-led containers (`min-height: 540px` on desktop) with `10px` inner media insets and `18px–26px` lower metadata padding.
- **Surface Alternation**: Cards alternate dynamically between `--pop-pink`, `--pop-yellow`, and `--pop-blue`.
- **Hover Behavior**: Restrained lift `translateY(-2px)` with subtle `1.025x` image scale transition (`cubic-bezier(0.2, 0.8, 0.2, 1)` over 500ms).

### 1.2. Interactive Buttons and Action Pills
- **Dimensions**: Fixed `44px` to `52px` touch-compliant height with `14px` border radius.
- **States**:
  - Default: Solid fill with 1px dark border (`--pop-border`).
  - Hover: Background flips to high-chroma contrast; action arrow translates `+2px, -2px`.
  - Focus: Clear 2px solid purple focus ring (`offset: 2px`).

### 1.3. Service Accordion Stack
- Stacked full-width rows with alternating colored header surfaces (`#ffe44f`, `#2444ca`, `#ff7eb5`).
- Expanded state smoothly reveals a two-column warm cream panel containing scope, deliverables, and case study links.

### 1.4. Lightbox and Modal Overlays
- Native HTML `<dialog>` elements providing built-in modal focus traps and Escape-key closure.
- Full viewport background backdrop: `rgba(21, 19, 15, 0.88)` with `backdrop-filter: blur(8px)`.
- Keyboard navigation: Left/Right arrows cycle gallery slides; Escape returns focus to triggering element.

## 2. Motion and Transition Guidelines

```css
:root {
  --pop-motion: 180ms ease;
  --pop-motion-slow: 550ms cubic-bezier(0.2, 0.8, 0.2, 1);
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

- **Native View Transitions**: Supported on multi-page navigation for seamless cross-document morphing.
- **Scroll Pacing**: Native smooth scrolling without artificial momentum hijacking.

## 3. Specialized Interaction Primitives

### 3.1. Kinetic Log-Spring Reticle Slider (`pop-kinetic-slider`)
*A continuous, tactile slider interaction pattern combining instantaneous 1:1 dragging, spring overshoot on click, crisp sub-frame scaling, and deferred layout execution.*

#### A. Motion & Easing Specifications
- **Glide on Click (Spring Overshoot & Soft Land)**:
  `transition: left 380ms cubic-bezier(0.18, 1.25, 0.4, 1)`
  *High initial velocity that rushes to the target coordinate, overshoots by ~6–8%, and softly cushions into dead-center alignment.*
- **Sub-Frame Tactile Scaling (Grab/Release)**:
  `transition: transform 120ms cubic-bezier(0.2, 0, 0, 1), box-shadow 120ms ease-out`
  *Expands to `scale(1.18)` on grab/down in 120ms; contracts to `scale(1.0)` on release in 120ms.*
- **Instantaneous Drag Tracking**:
  `transition: left 0s !important` (active while dragging)
  *Bypasses position transitions during active pointermove to eliminate input lag.*

#### B. Architectural Rules (Zero Layout Thrashing)
1. **Locked Coordinate Frame**: Cache `trackRect = track.getBoundingClientRect()` on `pointerdown` so `(e.clientX - trackRect.left) / trackRect.width` is locked against DOM resizing mid-interaction.
2. **Deferred State Commit**: Heavy filtering and text layout badges are committed only on `pointerup`. During drag, only the reticle thumb position and reticle background color update.
3. **Dead-Center Reticle Geometry**: Position reticle with `top: 50%; left: ${t * 100}%; transform: translate(-50%, -50%);` to guarantee cursor crosshair alignment.
4. **No Color Transition Muddiness**: Omit CSS `transition: background-color` on the reticle thumb so the target hex displays crisply without muddy RGB intermediate blending.
