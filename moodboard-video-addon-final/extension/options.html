Video → GIF → Moodboard

Separate from your existing image downloader. Your Mac bridge must be installed and running. It converts the complete Pinterest video into an animated GIF under 20 MB, then the existing R2 image pipeline takes over.

The pairing key and API token stay in this extension's private Chrome storage. The local key is sent only to the local bridge, and the Moodboard token is sent only to abodid.com.
