# Google sign-in assets

`g-logo.png` is the unmodified Google G downloaded from:
https://developers.google.com/static/identity/images/g-logo.png

Use on a white sign-in button following:
https://developers.google.com/identity/branding-guidelines

The Google Sans font in `public/fonts/google-sans/` is a Google Fonts sign-in-label subset at weight 500, distributed with its OFL license. Assets are hosted locally; rendering the button adds no Google SDK, tracking request, or change to the existing Supabase OAuth flow.

## Chrome logo

`chrome-logo.svg` is the unmodified Chrome product logo from:
https://www.google.com/chrome/static/images/chrome-logo.svg

It identifies the Chrome extension installation action and is served locally.
